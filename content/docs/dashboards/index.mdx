## Reporting period filter

Both dashboards include a **reporting period** time filter that controls the
data shown across all widgets and charts. **Current Year** is selected by
default.

<Steps>

<Step>
### Open the period filter
Select the period button at the top right of the dashboard (it shows the
current period, for example **Current Year**).

<Screenshot src="/images/dashboards/dashboard-period-edit.png" alt="Dashboard header with the period filter and Edit Dashboard buttons highlighted" caption="(1) The reporting period filter. (2) Edit Dashboard, used to customize widgets." />
</Step>

<Step>
### Choose a period
Under **Report Period**, select one of the preset periods:

- Current Month to date
- This Month
- Last Month
- Last Quarter
- YTD
- Current Year
- Last Year

To use your own dates, enter a **Start Date** and **End Date** under **Custom
Range** and select **Apply**. Select **Reset** to clear the custom dates.

<Screenshot src="/images/dashboards/dashboard-report-period.png" alt="Report period menu with preset periods and custom range" caption="(1) Preset report periods — the selected period shows a check mark. (2) Custom Range with Start Date, End Date, Reset, and Apply." />
</Step>

</Steps>

Once a period is selected, all metrics, charts, and summaries refresh
dynamically.
