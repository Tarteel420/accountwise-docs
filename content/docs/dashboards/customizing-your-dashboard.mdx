---
title: Customizing Your Dashboard
description: Show or hide widgets and rearrange the dashboard layout.
---

You can personalize your dashboard by choosing which widgets appear and how they
are arranged. Available widgets depend on your
[role](/docs/getting-started/user-roles).

## Enter Layout Edit Mode

<Steps>

<Step>
### Select Edit Dashboard
On the dashboard, select **Edit Dashboard** at the top right. The tooltip reads
*Edit layout and customize widgets*.

<Screenshot src="/images/dashboards/dashboard-period-edit.png" alt="Dashboard header with Edit Dashboard highlighted" caption="Select Edit Dashboard (2) to start customizing." />
</Step>

<Step>
### Rearrange widgets
The dashboard switches to **Layout Edit Mode — drag widgets to reposition**.
Each widget now shows a header bar with its name and a drag handle. Drag a
widget by its header to move it to a new position.

<Screenshot src="/images/dashboards/dashboard-edit-mode.png" alt="Dashboard in Layout Edit Mode" caption="Layout Edit Mode: (1) Cancel, (2) Customize, (3) Save Layout, (4) the drag handle on each widget." />
</Step>

<Step>
### Save or cancel
Select **Save Layout** to keep your changes, or **Cancel** to leave Layout Edit
Mode without saving.
</Step>

</Steps>

Your saved layout stays consistent across sessions and logins.

## Show or hide widgets

<Steps>

<Step>
### Open Customize
In Layout Edit Mode, select **Customize**. The **Customize Dashboard** panel
opens on the right: *Show or hide widgets. Drag them on the dashboard to
reorder.*
</Step>

<Step>
### Tick the widgets you want
Widgets are grouped into **Financial**, **Sales**, and **Purchases**. Tick a
widget's checkbox to show it, or clear the checkbox to hide it. Each widget is
labelled with its type — **Metric Card**, **Chart**, or **List**.

<Screenshot src="/images/dashboards/dashboard-customize.png" alt="Customize Dashboard panel" caption="(1) Tick or clear widgets. (2) Reset to default layout. (3) Close the panel." />
</Step>

<Step>
### Close the panel and save
Select the close (**×**) icon, then select **Save Layout**.
</Step>

</Steps>

To return to the original arrangement, select the **Reset to default layout**
icon at the top of the Customize Dashboard panel.
