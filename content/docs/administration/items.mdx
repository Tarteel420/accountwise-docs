The **Items Management** section lets you manage existing items and create new
ones. Items appear on sales and purchase documents through **Search AccountWise
Items**.

<Callout type="info">
  If your account is integrated with **Stock Wise**, sales documents pull items
  from Stock Wise instead. See [Sales Orders](/docs/sales/sales-orders).
</Callout>

## The Items list

Go to **Items Management** in the sidebar. The list shows each item's **Name**
(with its item number), **Description**, **Sales Account**, **Purchase
Account**, and **Price**.

<Screenshot src="/images/administration/items-list-annotated.jpg" alt="Items Management list" caption="(1) Export, (2) Import, (3) New Item, (4) Search items, (5) Edit and Delete." />

- Use **Search items...** to find an item.
- Use the row icons to **Edit** or **Delete** an item.
- Use **Export** to export the list, or **Import** to bulk import items.

## Creating an item

<Steps>

<Step>
### Open the form
On the Items Management page, select **New Item**.
</Step>

<Step>
### Enter the item details
Complete the fields:

| Field | Notes |
| --- | --- |
| Name | Required. |
| Description | Optional. |
| ASIN | Optional. |
| SKU | Optional. |
| Price | Required. |
| Sales Account | The account used when the item is sold. Required. |
| Purchase Account | The account used when the item is purchased. Required. |

<Screenshot src="/images/administration/items-new-annotated.jpg" alt="New Item dialog" caption="(1) Name, (2) Description, (3) ASIN and SKU, (4) Price, (5) Sales Account, (6) Purchase Account, (7) Create." width={760} />
</Step>

<Step>
### Save
Select **Create** to add the item, or **Cancel** to close the dialog.
</Step>

</Steps>
