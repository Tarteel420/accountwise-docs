---

The **Users** section lets administrators create users and control access to the
system.

## Open Users Management

Select **Users Management** at the bottom of the sidebar.

Users Management opens as a **separate application**. While it connects,
AccountWise shows **Connecting to Users Management...** and moves through three
steps:

1. **Validating authentication**
2. **Preparing your session**
3. **Redirecting to Users Management**

<Callout type="info">
  The **Users Management** item is only shown to users who have access to user
  management.
</Callout>

## Creating a user

Provide the following required fields:

| Field | Notes |
| --- | --- |
| Username | Used to log in. |
| Name | The user's full name. |
| Email | Contact email. |
| Password | Used to log in. |
| Role | Defines access — see [Roles & Profiles](/docs/administration/roles-and-profiles). |

After the user is created, the username and password are used to log in.

<Callout type="info">
  To view the permissions of each role or create a new role, go to **Settings →
  Role & Permission** inside AccountWise. See [Roles &
  Profiles](/docs/administration/roles-and-profiles).
</Callout>
