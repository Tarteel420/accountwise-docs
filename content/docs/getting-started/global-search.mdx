**Global search** lets you search across AccountWise from a single entry point.
The search bar sits at the top of every page, so you can find a customer,
vendor, or document without first opening its list.

<Screenshot src="/images/getting-started/topbar-search-docs.jpg" alt="Top bar with the search bar and Docs button" caption="(1) The search bar, available on every page. (2) Docs opens this documentation." />

## What you can search

Search matches **names** and **document numbers** — for example, a customer or
vendor name, an invoice number, or a bill number.

<Callout type="info">
  The items on a document's lines (for example, a product on an invoice) are
  **not** included in search. To analyse sales or purchases by item, use the
  [Item Reports](/docs/reports/item-reports).
</Callout>

## Searching

<Steps>

<Step>
### Open search
Select the search bar at the top of the page, or press **Ctrl K**. The search
window opens.
</Step>

<Step>
### Narrow the area (optional)
Choose a tab to search one area only: **All**, **Customers**, **Vendors**,
**Employees**, **Sales**, **Purchases**, **Banking**, or **Accounting**.
Searching a single area is quicker when you already know where the record is.
</Step>

<Step>
### Type a keyword
Type a name or document number. Results appear as you type:

- The tabs show how many matches each area has — for example, **Sales 21**.
- The **Top Match** appears first. Below it, results are grouped by type —
  for example, **Customers**, **Invoices**, and **Bills** — each with its
  count.
- Each result shows key details at a glance, such as the customer name, dates,
  amount, and status.

<Screenshot src="/images/getting-started/global-search-results.jpg" alt="Search results in the search window" caption="(1) Keyword, (2) area tabs with match counts, (3) Top Match, (4) preview of the selected result, (5) open the record, (6) See all results." />
</Step>

<Step>
### Preview and open a result
Select or move to a result to see its **preview** on the right — for example,
a vendor's email, phone, category, payment terms, sales rep, and location. Use
the copy icons to copy a value.

To go to the record, select it, press **Enter**, or select the open button in
the preview (for example, **Open vendor** or **Open invoice**). AccountWise
opens the record's detail page.
</Step>

</Steps>

### Keyboard shortcuts

| Key | Action |
| --- | --- |
| **Ctrl K** | Open search. |
| **↑ ↓** | Move between results. |
| **Enter** | Open the selected result. |
| **Tab** | Move between the type tabs. |
| **Esc** | Close search. |

## See all results

The search window shows a limited set of results. To see every match, select
**See all … results** at the bottom of the window. The **Search results** page
opens.

<Screenshot src="/images/getting-started/global-search-all-results.jpg" alt="Search results page" caption="(1) Search AccountWise, (2) area tabs with counts, (3) results summary, (4) Rows or Compact view." />

- Change the keyword in **Search AccountWise**.
- Use the tabs to filter the results by area.
- The summary shows how many results were found, in how many types, and how
  many **need action**.
- Results are grouped in tables by type (for example, **Vendors** and
  **Customers**). Switch between **Rows** and **Compact** views.

## Recent searches and recently viewed

When you open search without typing, the window shows:

- **Recent searches** — the keywords you searched before. Select one to search
  it again, or select **×** to remove it. Recent searches are kept, so they are
  still there the next time you use search.
- **Recently viewed** — the records you opened recently, with how long ago you
  viewed them. Select one to preview it, or open it again.

Select **Clear** next to either heading to clear that list.

<Screenshot src="/images/getting-started/global-search-recent.jpg" alt="Recent searches and recently viewed" caption="(1) Area tabs, (2) Recent searches, (3) Recently viewed, (4) Copy # and Open invoice for the selected record." />

## Opening the documentation

Select **Docs** in the top bar (next to the notifications icon) to open the
AccountWise documentation in a new browser tab. From there you can search the
documentation or browse it by module.
