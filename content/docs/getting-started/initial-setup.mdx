Before recording transactions, an **Admin** should make sure the foundations
are in place. This page lists the recommended setup order with links to the
detailed guides.

<Callout type="info">
  Most setup tasks require the Admin role. See [User
  Roles](/docs/getting-started/user-roles).
</Callout>

## Recommended setup order

<Steps>

<Step>
### Review the Chart of Accounts
Confirm your account structure. Default system accounts are already present and
cannot be edited or deleted, but you can add your own. See [Chart of
Accounts](/docs/accounting/chart-of-accounts).
</Step>

<Step>
### Add locations
Set up the business locations you operate from. See
[Locations](/docs/administration/locations).
</Step>

<Step>
### Create users
Add the people who will use the system and assign each a role. See
[Users](/docs/administration/users).
</Step>

<Step>
### Add items
Set up the products or services you buy and sell. See
[Items](/docs/administration/items).
</Step>

<Step>
### Configure documents (optional)
Customize how sales and purchase documents and reports appear. See
[Customization](/docs/administration/customization).
</Step>

<Step>
### Configure customer settings (optional)
Choose which customer fields are required in the [Customer Fields
Map](/docs/administration/customer-fields-map), and decide who can move
customers between lifecycle stages in [Customer Lifecycle
Transitions](/docs/administration/customer-lifecycle-transitions).
</Step>

<Step>
### Set up approvals and asset categories (optional)
If documents need sign-off before they take effect, set up an [approval
policy](/docs/administration/approvals). If you track fixed assets, create
[Fixed Asset Categories](/docs/banking/fixed-asset-categories) so new assets
get their depreciation settings filled in.
</Step>

</Steps>
