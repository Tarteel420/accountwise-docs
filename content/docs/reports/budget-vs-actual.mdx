**Budget vs Actual** compares the budgets you set up in
[Budgeting](/docs/banking/budgeting) with your actual financial results. Open it
from **Reports → Budget vs Actual**.

## Running the report

<Steps>

<Step>
### Choose the filters
Choose the **Year** (required), and optionally a **Location** and **Account**.

<Screenshot src="/images/reports/budget-vs-actual.jpg" alt="Budget vs Actual report" caption="(1) Year, (2) Location, (3) Account, (4) Apply, (5) chart type: Area, Bar, or Mixed, (6) toggle scale type." />
</Step>

<Step>
### Apply
Select **Apply**. For the rest of the filter bar, see [Running a
report](/docs/reports#running-a-report).
</Step>

</Steps>

## What the report shows

The **Budget vs Actual Analysis** chart gives a monthly comparison for the
year, with the total **Budget** and **Actual** amounts above it. Switch the
chart between **Area**, **Bar**, and **Mixed**, and use the scale toggle to
change the chart's scale type.

Below the chart, the table shows each account, followed by a **Total** row:

| Column | Description |
| --- | --- |
| **Account Code** | The account's code. |
| **Account Name** | The account's name. |
| **Budget Amount** | The budgeted amount. |
| **Actual Amount** | The actual amount recorded. |
| **Variance ($)** | The difference between budget and actual. |
| **Variance (%)** | The difference as a percentage. |
