AccountWise provides a library of reports to help you analyze financial data
across accounts, locations, and time periods. Open them from **Reports** in the
sidebar.

<Screenshot src="/images/reports/reports-menu.png" alt="Reports menu in the sidebar" caption="(1) Select Reports in the sidebar to expand the list of reports." width={520} />

The **Reports** menu contains **General Ledger**, **Trial Balance**, **Income
Statement**, **Balance Sheet**, **Asset Register**, **Bank Register**,
**Customer Reports**, **Vendor Reports**, **Item Reports**, **Salesperson
Reports**, **Purchase Reports**, and **Budget vs Actual**. Entries with an arrow
expand to show the individual reports.

## Running a report

Every report page has the same filter bar at the top.

<Screenshot src="/images/reports/report-toolbar.png" alt="Report filter bar" caption="(1) Report Period, (2) Start Date and End Date, (3) Advanced, (4) report-specific filters, (5) Apply, (6) Save Filter, (7) Export, (8) applied filters and Clear." />

<Steps>

<Step>
### Choose the period
Pick a **Report Period** — **Current Month to Date**, **Last Month**, **Last 3
Months**, **Last 6 Months**, **Last 12 Months**, **Current Year to Date**, or
**Last Year** — or enter a **Start Date** and **End Date**.
</Step>

<Step>
### Set any other filters
Select **Advanced** to show the filters for that report, for example
**Location**, **Customer Name**, or **Account**. Each report page lists its
filters.
</Step>

<Step>
### Apply
Select **Apply**. The applied filters appear as chips under the filter bar.
Remove one with its **×**, or select **Clear** to remove them all.
</Step>

<Step>
### Export (optional)
Select **Export** (download icon) to download the report as an Excel (.xlsx)
file.
</Step>

</Steps>
