---
title: Additional Surcharges
description: Define flat or percentage surcharges applied to documents.
---

AccountWise lets you create **additional surcharges** that can be applied to
documents — for example, shipping or delivery charges.

## The Additional Surcharge list

Go to **Sales → Additional Surcharge**. The list shows each surcharge's
**Name**, **Type**, **Price**, and linked **Chart of Account**.

<Screenshot src="/images/sales/surcharge-list-annotated.jpg" alt="Additional Surcharge list" caption="(1) Add New Additional Surcharge, (2) All, Flat, and Percentage tabs, (3) Search, (4) Edit and Delete." />

Use the **All**, **Flat**, and **Percentage** tabs to filter by type, and the
row icons to **Edit** or **Delete** a surcharge.

## Creating a surcharge

<Steps>

<Step>
### Open the form
On the Additional Surcharge page, select **Add New Additional Surcharge**.
</Step>

<Step>
### Define the surcharge
Complete the fields:

| Field | Notes |
| --- | --- |
| Surcharge Name | Required. |
| Type | **Flat** or **Percentage**. Required. |
| Price | The amount or percentage. Required. |
| Chart of Account | The account the surcharge posts to. Required. |
| Set as Default | Turn on to apply the surcharge automatically during document creation. |
| Applied On | **Total** (the document total) or **Line Items Total**. |

<Screenshot src="/images/sales/surcharge-new-annotated.jpg" alt="Add New Additional Surcharge dialog" caption="(1) Surcharge Name, (2) Type, (3) Price, (4) Chart of Account, (5) Set as Default, (6) Applied On, (7) Create." width={760} />
</Step>

<Step>
### Save
Select **Create** to save the surcharge, or **Cancel** to close without
saving.
</Step>

</Steps>

## Using surcharges on documents

On invoices, sales orders, and sales receipts, select **Add Additional
Surcharge** under **Details** to add a surcharge to the document. Surcharges can
also be set on a customer's profile under **Additional surcharges**. See
[Creating Customers](/docs/sales/customers/creating-customers).

## Default surcharges

A surcharge can be set as **default**, so it is applied automatically during
document creation.
