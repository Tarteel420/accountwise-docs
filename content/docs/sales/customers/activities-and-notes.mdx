AccountWise lets you keep a record of your communication and internal notes for
each customer.

## Activities

Record activities such as:

- Meetings
- Calls
- Tasks
- Emails

### The Activities list

Go to **Customers Management → Activities** to see activities across all
customers.

The list is split into tabs:

- **To Do**
- **Completed**
- **Cancelled**
- **All**

You can filter the list by **Customers**, **Lead**, **Assigned user**, and
**Type**, search by keyword, and narrow results with **Date range**.

The columns show **Date & Time**, **Assigned To**, **Customer**,
**Description**, **Regarding**, **Type**, **Priority**, and **Status**. You can
change an activity's status directly from the **Status** dropdown on its row.

<Screenshot src="/images/sales/customers/activities-list.jpg" alt="Customer Activities list" caption="(1) New activity, (2) status tabs, (3) filters, search, and Date range, (4) the Status dropdown on each row." />

### Create an activity

<Steps>

<Step>
### Open the form
From **Customers Management → Activities**, select **New activity**. The
**Create a new activity** page opens.
</Step>

<Step>
### Choose who it is for
Complete the **Customers** and **Lead** fields at the top of the form. Both
are marked as required.
</Step>

<Step>
### Select the type
Under **Select type**, choose **Call** or **Meeting**.
</Step>

<Step>
### Enter the details
Fill in the activity details:

| Field | Notes |
| --- | --- |
| Scheduled for | The user responsible for the activity. Required. |
| Regarding | A short subject, up to 50 characters. |
| Priority | For example, **Low**. Required. |
| Duration | For example, **10 Min**. Required. |
| Start date & time | Required. |
| End date & time | Required. |
| Description | Optional details. |

**Scheduled for** is filled in with your name, and **Priority** and
**Duration** start at **Low** and **10 Min**. Change them as needed.

<Screenshot src="/images/sales/customers/new-activity-1.jpg" alt="Create a new activity form" caption="(1) Customers, (2) Lead, (3) Select type, (4) Scheduled for, (5) Regarding, (6) Priority, (7) Duration, (8) Start date & time, (9) End date & time." />
</Step>

<Step>
### Save
Select **Save** to create the activity, or **Cancel** to discard it.

<Screenshot src="/images/sales/customers/new-activity-2.jpg" alt="Description field and Save button" caption="(10) Description, (11) Save." />
</Step>

</Steps>

You can also open a customer's record and use its **Activities** tab to see and
add activities for that customer only. See [Customer
Details](/docs/sales/customers/customer-details#activities).

## Notes

Add **notes** for internal reference on the customer record. Open the customer,
select the **Notes** tab, and select **New note**. Enter an optional **Title**
and the **Description**, then select **Add**. See [Customer
Details](/docs/sales/customers/customer-details#notes).

<Screenshot src="/images/sales/customers/customer-add-note.jpg" alt="Add note dialog" caption="The Add note dialog: (1) Title, (2) Description." />
