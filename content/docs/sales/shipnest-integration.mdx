title: Shipnest Integration
description: Automatically create Shipnest orders from AccountWise.
---

The **Shipnest** integration is configurable and connects order creation between
AccountWise and Shipnest.

## Automatic order creation

When a customer payment is received in AccountWise, the system can automatically
create a corresponding **order in Shipnest** — no manual order creation needed.

## Creating orders manually

While creating an [Invoice](/docs/sales/invoices) or [Sales
Order](/docs/sales/sales-orders), you can choose to create a Shipnest order
directly using the **Create Shipnest Order** field on the form.

<Screenshot src="/images/sales/invoice-new-2.jpg" alt="Create Shipnest Order field on the New invoice form" caption="The Create Shipnest Order field (10) on the New invoice form." />

<Callout type="info">
  All Shipnest orders created through AccountWise appear on the Shipnest listing
  page for tracking and management.
</Callout>
