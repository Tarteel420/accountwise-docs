---
title: Glossary
description: Key terms used across AccountWise.
---

| Term | Meaning |
| --- | --- |
| Accounts Receivable (AR) | Money owed to you by customers. |
| Accounts Payable (AP) | Money you owe to vendors. |
| Chart of Accounts | The five-type account structure the system posts to. |
| Journal Entry | The debit/credit record behind a transaction. |
| GL Impact | The General Ledger effect of a document. |
| Credit Memo | A customer credit for advances, returns, or adjustments. |
| Vendor Credit | A vendor credit for returns, overpayments, or adjustments. |
| Undeposited | A payment received but not yet deposited to a bank. |
| Reconciliation | Matching bank statements to system records. |
| Closing Date | A date before which new documents cannot be created. |
| R2 Certified | A certification flag stored on customers and vendors. |
| Customer Assignment | The link between a customer and one or more salespersons; controls which customers a salesperson can see. |
| Lifecycle stage | The stage a customer record is in: Lead, Prospect, Customer, Inactive, or Archived. |
| Customer Fields Map | The setting that decides which customer profile fields are required, optional, or conditionally required. |
| Approval workflow | Requiring a document to be approved before it takes effect. See [Approval Workflow](/docs/administration/approvals). |
| Pending approval | The status of a document, or a change to it, that is waiting for an approver's decision. |
| Fixed asset category | A group of fixed assets that share a depreciation method, useful life or rate, and accounts. |
| Net Book Value (NBV) | An asset's cost minus its accumulated depreciation. |
| Residual value | The value an asset is expected to have at the end of its life, as a percentage of its cost. |
| Write-off account | The expense account used when a fixed asset is disposed of. |
| Write-down account | The expense account used to reduce a fixed asset's value while it is still depreciating. |
