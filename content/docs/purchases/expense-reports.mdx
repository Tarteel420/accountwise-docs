**Expense Reports** let you create and manage expense reports against
[employees](/docs/administration/employees).

## The Expense Report list

Go to **Purchase → Expense Report**.

<Screenshot src="/images/purchases/expense-report-list-annotated.jpg" alt="Expense Report list" caption="(1) New Expense Report, (2) status tabs, (3) Employee, Start date, End date, and Search filters, (4) View, Edit, Delete, and See more." />

- **Status tabs** — **All**, **Draft**, **Unpaid**, **Partial**, **Paid**, and
  **Overdue**, each with a count.
- **Columns** — Employee (with the report number), Expense Date, Due Date,
  Quantity, Amount, Paid Amount, Status, and Actions.

## Creating an expense report

<Steps>

<Step>
### Open the form
Go to **Purchase → Expense Report** and select **New Expense Report**.
</Step>

<Step>
### Select the employee and enter the header details
Choose the employee in **Select Employee**. Optionally enter a **Reference
Number** and **Email**, and check the **Expense Report Date**, **Due Date**,
**Tax Type**, and **Discount Type**. Optionally choose a **Location**.

<Screenshot src="/images/purchases/expense-report-new-annotated.jpg" alt="New Expense Report form" caption="(1) Select Employee, (2) Reference Number, (3) Email, (4) Expense Report Date, (5) Due Date, (6) Tax Type, (7) Discount Type, (8) Location, (9) Add Item." />
</Step>

<Step>
### Add expense details
Under **Details**, select **Add Item** to add each expense line with its details
and amount. Enter any **tax** and **discount**, and add **Notes** if needed.
</Step>

<Step>
### Save
Add any **Attachments** and **Terms and Conditions**, then select **Save as
Draft**, **Create**, or **Create & Send**.
</Step>

</Steps>

## Paying an expense report

Expense reports are paid from [Bill Payments](/docs/purchases/bill-payments) by
choosing **Employee** instead of **Vendor**.
