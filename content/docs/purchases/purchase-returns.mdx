title: Purchase Returns
description: Return items to a vendor after a bill has been created.
---

A **Purchase Return** is recorded when items are returned to a vendor **after a
bill has been created**.

## The Purchase Returns list

Go to **Purchase → Purchase Return**. The list shows the Vendor (with the return
number), Purchase Return Date, and Amount.

<Screenshot src="/images/purchases/purchase-return-list-annotated.jpg" alt="Purchase Returns list" caption="(1) New Purchase Return, (2) Vendors, Start date, End date, and Search filters." />

## Creating a purchase return

<Steps>

<Step>
### Open the form
Go to **Purchase → Purchase Return** and select **New Purchase Return**.
</Step>

<Step>
### Select the vendor and enter the return details
Choose the vendor in **Select Vendor** — the **Mailing Address** is filled in.
Enter the **Reference Number** and **Email**, check the **Purchase Return
Date**, and set the **Payment Method** and the **Deposit To** account. Select
the related **Bill** and, optionally, a **Location**.

<Screenshot src="/images/purchases/purchase-return-new-annotated.jpg" alt="New Purchase Return form" caption="(1) Select Vendor, (2) Reference Number, (3) Email, (4) Purchase Return Date, (5) Payment Method, (6) Deposit To, (7) Bill, (8) Location." />
</Step>

<Step>
### Add returned items
Under **Details**, select the **Vendor Credit** if applicable, and enter the
**Description**, **Quantity**, **Rate**, and **Amount** for each returned item.
Select **Add Line Item** for more lines.
</Step>

<Step>
### Save
Add any **Attachments**, complete the **Terms and Conditions** (required), and
select **Create** or **Create & Send**.
</Step>

</Steps>

## What it affects

- Adjusts **inventory** (if applicable).
- Reduces **Accounts Payable** accordingly.
